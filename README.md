# Shark Is Hungry (Dev Build)

An original 3D arcade shark game inspired by the hungry-shark genre. Three.js (bundled in /lib), no build step, runs on GitHub Pages.

- 6 original procedural 3D sharks with distinct silhouettes (hammerhead, striped tiger, glowing Neon Reaper, scarred Megalodon...)
- Dev build: everything unlocked, upgrade shop, dev tools (god mode, spawners, time scale)
- Controls: mouse / touch / WASD to swim, hold click / Space / Shift / button to boost, Esc to pause
